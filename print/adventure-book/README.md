# LAB QUEST『冒険の書』表紙

紙媒体の教科書役として使う **冒険の書** のA4表紙です。Wordに貼って使う想定です。

## ファイル

| ファイル | 用途 |
|---|---|
| `cover-a4.png` | 完成表紙（A4・約288dpi）。Wordに挿入する画像 |
| `冒険の書-表紙.docx` | 上記画像をA4全面に置いたWordファイル |
| `art/cover-bg.png` | 金の飾り枠＋白ベースのグラデーション背景だけ |
| `cover.html` | 表紙の組み版ソース（ロゴ・文言の再出力用） |

## Wordへの入れ方

完成稿を使う場合:

1. `冒険の書-表紙.docx` を開く  
   または新規A4文書を作り、余白をすべて 0 mm にして `cover-a4.png` を挿入し、幅 210 mm × 高さ 297 mm にする
2. 余白の細い隙間が出たら、画像の折り返しを「背面」にし、ページの端まで広げる
3. 2ページ目以降は通常余白（上下左右 20 mm 程度）に戻して本文を書く

文字を差し替えたい場合は、`art/cover-bg.png` をページ背景（または背面画像）にし、`public/art/quest-brand-title.png` をロゴとして重ね、下の指定で打ち直してください。

## デザインの考え方

- **白ベース**で、色は中央に置く。左寄りにペールティール、下〜右寄りに薄い羊皮紙ゴールド。外周は純白へ溶かし、白い紙に印刷したときに余白との境目が出ないようにしている
- **ラボクエストのロゴ**（金文字＋フラスコの Q）を上部の徽章として置く
- 中央の大タイトルを **冒険の書** にし、英語の `THE BOOK OF ADVENTURE` を添えて、紙の冊子の役割がすぐ分かるようにする
- 下部の薄いフラスコは「書の封蝋」代わり。角の金の飾り枠は手帳・冒険日誌の合図

## 文言

- 徽章: LAB QUEST / Biochemistry and Immunology（ロゴ画像のまま）
- 英語ラベル: THE BOOK OF ADVENTURE
- メイン: 冒険の書
- サブ: 臨地実習の手引き
- キャッチ: 検査室は、冒険の拠点になる
- フッタ: CLINICAL PRACTICUM / 生化学・免疫検査　臨地実習（学校名に差し替えてよい）

```bash
print/adventure-book/render-cover.sh
pip install python-docx
python3 print/adventure-book/build-docx.py
```
