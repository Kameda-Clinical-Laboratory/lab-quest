想定：図解1分 ＋ モックアップ操作3分。読み上げはややゆっくり。  
操作は【】で示す。

## 事前準備

1. 図解を全画面表示（`creating-visual-explainers/output/lab-quest.html` をブラウザで開く）
2. 別タブで `npm run dev` → モックを用意  
   - 実習生：受講コード `TRAIN01` / パスワード `1234`（ホームが開いた状態が理想）

## Part A｜図解（約1分）

【図解のヒーロー〜一枚絵サマリーを表示】

臨地実習の朝、指導者はルーチンで手が一杯です。  
実習生は教科書を持っている。でも「いま現場で何を見て、どう判断するか」は、そばに先輩がいないと止まりがちです。

今日お見せするのは、その空白を埋めるWebアプリのモックです。  
名前は **生化学免疫ラボクエスト**。

【一枚絵の4ステップを指しながら】

一言でいうと、**実習カレンダーに沿ってシリーズ学習し、途中は繰り越し、最終日はクリアした範囲だけで確認テストを受ける**アプリです。  
ゲームの見た目は「続けたくなるため」。中身は、実習の運用に合わせています。

午前はアプリで自習、午後は現場。指導者が毎回ゼロから教えるのではなく、事前に学習パックを組んで、当日は現場へ集中する——それが狙いです。

（ここで図解を閉じ／最小化し、モックのタブへ切り替え）

## Part B｜モックアップ操作（約3分）

### B-1 実習生ホーム（約70秒）

【ログイン後のホームを表示】  
ここが冒険マップです。今日のクエスト、繰り越し、XPとスタンプが見えます。

山田さんのモックでは、前日の「基礎知識」が途中のため、**繰り越し**が出ています。  
その下に、本日計画のシリーズが並びます。

【日付ボタンで 8/12 を押す】  
シリーズゼロの日は、見学など「アプリなし」と出ます。学校によって実習日数も、見学の入り方も違うので、カレンダーで本数を変えられるようにしています。

【8/11 に戻す → 「基礎知識」または本日シリーズを1つ開く】  
中は、短い講義→確認問題を繰り返すチャプター、そのあと症例。手技ありなら手順チェックまでがクリア条件です。実務に出る前のゲート、という位置づけです。

### B-2 管理者（約55秒）

【スタッフ用タブ、またはログアウトして `/staff/login` → `ops`】  
実習生画面では、氏名・パスワード・**実習カレンダー**を押し、日付ごとにシリーズを割り当てます。  
0本なら見学日。必須が未割当なら保存時に警告します。

【進捗タブ】  
誰の必須が残っているか、今日のキュー、繰り越し、CBT素点が一覧できます。進捗は口頭ではなく、ここで追います。

### B-3 最終CBT（約40秒）

【実習生に戻り、最終確認テストへ】  
合否はありません。**クリア済みシリーズの問題だけ**から、ランダムに最大30問を組みます。  
開始ボタンで出題が確定し、提出後に解説が見られます。理解度の換算は指導者が行い、評価表の参考にする素点です。

### B-4 締め（約15秒）

こうなると、指導者が手を離せない午前でも、実習生は臨床寄りの課題を進められます。  
日数が違っても、カレンダーで組めば、同じ仕組みで回せます。

生化学免疫ラボクエストは、まだモックです。これから中身を一緒に作り込みます。  
今日お伝えしたかったことは一つだけです。  
**忙しさを理由に、臨床の学びを止めない。**  
ご清聴ありがとうございました。
