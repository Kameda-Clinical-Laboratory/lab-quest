## 3. ③調査ビートへの3ギミック導入

### 3-1. 穴埋め(新規puzzleType、仮称 `cloze`)

**仕様(ユーザー要望より)**:

1. 元ネタは現行の講義本文(lecture.body)相当のテキスト
2. 文章中の重要語句を歯抜けにする
3. 歯抜け箇所には**文字数のヒント + インライン入力フォーム**を文中に配置する
4. 解答は**すべてひらがなで入力**させる(漢字・カタカナの変換揺れや厳密一致判定の問題を避けるため)
5. **すべての歯抜けが正解して初めて次(判断)へ進める**

**位置づけ**: §2の「講義を省略してこの穴埋め型調査に知識を持たせる」運用と対になる新ギミック。読ませたい文章そのものに空欄を作ることで、読解と穴埋めが一体化する。

**既存cipher型との違い(明記しておくべき点)**: cipherは「1問正解ごとに文字を1つ集め、後で並べ替えて言葉を完成させる」方式で、§3.5の結論により不採用済み(=正解後の付随演出であり、読解そのものとは無関係だった)。今回のclozeは「読んでいる文章そのものに空欄があり、その場で埋める」方式で、狙いは**知識の定着(読解)**であり、cipherが狙っていた「集めて並べ替える達成感」とは別物。

**§3.5(対立仮説の消去)との関係**: 競合しない。clozeは知識のインプット段階(読解定着)、対立仮説消去は判断のアウトプット段階(仮説の絞り込み)という別軸。**「clozeで知識定着 → board型で対立仮説消去 → resolveで判断」という役割分担**にできる。
