## カテゴリA:検体の溶血(pre-analytical artifact — 偽高値/偽低値の原因としての溶血)

骨子案4-Aが対象とする「採血・検体取り扱いに伴う溶血が測定値を狂わせる」パターン。件数は少ないが、いずれも教材として直接使える良問。

### A-1. 模擬②AM1 問14 ★最重要
> 採血を手間どった患者の血液検査で、溶血により**高値**となるのはどれか。
> 1. Na　2. Cl　3. Ca　4. pH　5. ヘモグロビン〈Hb〉

「採血に難渋する→溶血が起こる」という臨床場面をそのまま問題文にした設問。選択肢がNa・Cl・Ca・pHという「実は溶血の影響をほとんど受けない電解質・pH」で揃えられており、正答はヘモグロビンそのもの(赤血球内成分がそのまま血漿中に漏出するため)。K(カリウム)が選択肢に入っていない点が逆にひっかけになっており、「溶血=Kが上がる」という一面的な暗記だけでは正答しにくい設計。並べ替え・暗号解錠型クエストの元ネタとして、電解質と血球内成分を仕分けさせる形式に転用しやすい。

### A-2. 模擬②AM1 問36
> ASTについて正しいのはどれか。
> 1〜4省略　5. 溶血検体では**低値**を示す。

正答は選択肢5ではない(=誤り選択肢としての「低値」)。実際にはAST(GOT)は赤血球中に血漿の約40倍存在するため、溶血検体では**高値**を示す。「溶血→低値」という誤った方向を選ばせるひっかけ問題であり、暗号解錠型クエスト(正しい方向を選ばないと解錠できない)の題材に好適。

### A-3. 第62回PM 問33 / 模擬①PM 問37(対になる良質ペア)
- **第62回PM 問33**: HbA1cが偽高値を示すのはどれか。
  1. 出血　2. 輸血　3. 鉄欠乏状態　4. 脾機能亢進　5. 溶血性貧血
- **模擬①PM 問37**: HbA1cについて誤っているのはどれか。
  (…) 5. 溶血性貧血では**低値**を示す。

両問とも「赤血球の寿命が短くなる(=溶血が起きている)とHbA1cへのグルコース結合時間が短くなり、HbA1cは低値方向に振れる」という同じ機序を問うている。第62回PM問33では「鉄欠乏状態(赤血球寿命が延びる)」が偽高値の原因として区別され、「溶血性貧血」は偽高値の原因としては誤り(=実際は偽低値方向)という位置づけ。模擬①PM問37は同じ事実を「溶血性貧血では低値を示す」という正しい記述として出題している。両者を並べると「検体そのものの溶血」ではなく「患者体内での病的な溶血(溶血性貧血)」がHbA1cという間接的な検査項目に影響する例だが、骨子案4-Aで扱う「溶血が検査値をどう歪めるか」という論点の応用編として使いやすい。

**追加調査(第63〜70回)で判明した同工異曲の設問**(いずれも同じ機序=溶血性貧血による赤血球寿命短縮→HbA1c偽低値、を問う): 
- **第65回AM 問38**: HPLC法によるHbA1c測定値が低下する要因はどれか。1. 尿毒症　2. 乳び血症　3. 溶血性貧血　4. アスピリンの大量摂取　5. アスコルビン酸の大量摂取。正答3(溶血性貧血)。
- **第66回AM 問33**: 過去1〜2か月の平均血糖値から想定されるHbA1c値より測定値が**高値**になるのはどれか。1. 輸血後　2. 腎性貧血　3. 大量出血後　4. 溶血性貧血　5. 鉄欠乏性貧血。正答5(鉄欠乏性貧血)。「高値になる」向きを問うことで、溶血性貧血(4、低値方向)を誤り選択肢として使う、第62回PM問33と対をなす良問。
- **第67回AM 問29**: 血糖コントロールの指標について正しいのはどれか。1. **HbA1cは溶血性疾患で低値になる。**　2〜5省略。正答1。事実を最も端的な肯定文で問う形式で、章の要点整理にそのまま使える。

これで「HbA1c偽低値=溶血性貧血」という論点は模擬試験1件・国家試験4回分(62・65・66・67回)で繰り返し出題されていることが確認できた。骨子案4-Aの応用パートで最も安定して出題される論点といえる。

参考として、同じ「赤血球内成分が血中へ漏出する」機序で**血清亜鉛**が高値化する例も見つかった。
- **第65回AM 問37**: 血清亜鉛が高値を示すのはどれか。1. 褥瘡　2. 妊娠　3. 低栄養　4. 味覚障害　5. 溶血性貧血。正答5。亜鉛は赤血球内に多く含まれるため、赤血球が破壊されると血清亜鉛が見かけ上上昇する。A-1のHb・K同様「赤血球内成分の漏出」という原理を敷衍でき、章の発展コーナー(なぜ溶血で特定の項目だけが動くのか)に使いやすい。

### A-4. 第63回PM 問13
> 血清と比較した血漿検体の特徴で正しいのはどれか。
> 1. 溶血が多い。　2. LD活性の偽高値が少ない。　3. 凝固因子が含まれていない。　4. 蛋白分画への影響が少ない。　5. 採血から測定までに時間がかかる。

正答は選択肢2。血清は凝固過程(血餅形成)で機械的な赤血球破壊が血漿より起こりやすく、それに伴いLD(赤血球内に豊富な酵素)の偽高値も血清の方が生じやすい。裏返せば「血漿は血清より溶血しにくく、LD偽高値が少ない」という関係になる。骨子案4-Aが扱う「採血管・検体の種類そのものが溶血由来の測定誤差を左右する」という論点にきわめて直接的に対応する設問で、A-1・A-2と並ぶ核心教材。

### A-5. 第70回PM 問39
> 血中アンモニア濃度で正しいのはどれか。
> 1. 成人では性差がある。　2. **溶血検体で低値を示す。**　3. 消化管出血により上昇する。　4. 採血後室温で放置すると低下する。　5. 動脈血のアンモニア濃度は静脈血より高い。

正答は選択肢3(消化管出血により上昇する)。選択肢2「溶血検体で低値を示す」は誤り選択肢で、実際は逆(赤血球内アンモニア濃度は血漿より高いため、溶血検体は**高値**を示す。また採血後の放置でもアンモニアは細胞内代謝により**上昇**する方向に動く点で選択肢4も誤り)。A-2(AST「溶血検体では低値を示す」も誤り選択肢)と全く同じ構造のひっかけで、「溶血=対象物質の高値」という基本則を裏から確認させる好例。A-2とセットで、暗号解錠型クエスト(方向を正しく選ばないと解錠できない)の素材を倍増できる。

### A-6. 第58回AM 問30(A-2・A-5の「正しい」向きを裏付ける本試験問題)
> 正しいのはどれか。
> 1. **溶血によって血清AST活性は上昇する。**　2. 全血冷蔵保存によって乳酸値は低下する。　3. 血清鉄は夜間の方が早朝よりも高値を示す。　4. 血清アルブミンは立位の方が臥位よりも低値を示す。　5. ヘパリン採血した血漿中のカルシウムは低値を示す。

正答は選択肢1。模擬②AM1問36(「AST…溶血検体では低値を示す」を誤り選択肢とする)の裏返しとして、「溶血によってASTは上昇する」という正しい向きをそのまま正答にした国家試験本試験問題。選択肢2〜5も全血保存条件・日内変動・体位・採血管添加物という、検体側の要因で検査値が動く「pre-analytical」の話題で統一されており、章の導入(検体側要因の総まとめ)にそのまま使える。

### A-7. 第58回AM 問37(A-5の「正しい」向きを裏付ける本試験問題)
> アンモニアについて正しいのはどれか。
> 1. 筋肉でリン酸化される。　2. **溶血で血漿中濃度が上昇する。**　3. TCA回路によって解毒される。　4. プリン体の最終代謝産物である。　5. 食物摂取によって血中濃度が低下する。

正答は選択肢2。第70回PM問39(「溶血検体で低値を示す」を誤り選択肢とする)と対になる問題で、こちらは正しい向き(赤血球内アンモニア濃度は血漿より高いため、溶血で血漿中濃度は上昇する)をそのまま正答として問うている。A-6のASTとあわせ、「溶血=対象物質の高値」という基本則を国家試験本試験の正答そのもので裏付けられる、章の核心教材。

## カテゴリB:溶血性貧血(疾患としての溶血)

「溶血」という語が最も高頻度で登場するのはこちらのカテゴリ(体内での病的な赤血球破壊とその検査所見)。骨子案4-Aの直接の対象ではないが、対比教材・発展クエストの元ネタとして使える。中核となる良問を挙げ、その他は出典と骨子のみ列挙する。

### B-1. 第61回AM 問64(中核となる良問)
> 溶血性貧血で低下するのはどれか。
> 1. LD　2. 間接ビリルビン　3. ハプトグロビン　4. フェリチン　5. 網赤血球数

正答はハプトグロビン(遊離ヘモグロビンと結合して消費されるため低下)。他の4つ(LD・間接ビリルビン・フェリチン・網赤血球数)はいずれも溶血性貧血で**上昇**する。溶血性貧血の検査所見一式を「上がるもの/下がるもの」に仕分けさせる好例。

**同工異曲**: 第63回AM 問63「溶血性貧血で低下または減少するのはどれか。1. 血清LD　2. 網赤血球数　3. **血清ハプトグロビン**　4. 血清間接ビリルビン　5. 尿中ウロビリノゲン」でも正答は3(ハプトグロビン)。選択肢の並びだけ変えたほぼ同一テーマの国家試験本試験問題で、B-1と合わせて使うと出題の安定した頻出パターンであることを示せる。

### B-2. 模擬①PM 問65(B-1の姉妹問題、2つ選べ形式)
> 自己免疫性溶血性貧血の所見はどれか。2つ選べ。
> 1. 血清ハプトグロビンの上昇　2. 血清LDの上昇　3. 血清直接ビリルビンの上昇　4. 網赤血球数の上昇　5. 尿中ビリルビンの上昇

正答は2・4(LD上昇、網赤血球上昇)。誤り選択肢が「ハプトグロビン**上昇**」(実際は低下)、「**直接**ビリルビン上昇」(実際は間接ビリルビンが上昇)、「尿中ビリルビン上昇」(間接ビリルビンは非水溶性で尿中に出ない=尿ビリルビン陰性)と、B-1と対になる形でひっかけ構成されている。B-1・B-2をセットで使うと「溶血性貧血の検査所見」を暗号解錠型(上昇/低下の二択を複数項目並べる)に組みやすい。

**国家試験本試験にも同型の設問がある**: 第67回AM 問65「自己免疫性溶血性貧血で高値を示すのはどれか。2つ選べ。1. フェリチン　2. **網赤血球数**　3. **間接ビリルビン**　4. ハプトグロビン　5. 総鉄結合能〈TIBC〉」正答2・3。B-2(模擬①PM問65)と選択肢の一部が異なる(フェリチン・TIBCが誤り選択肢として追加)ものの、問う内容はほぼ同一。模擬試験の問題が国家試験の出題パターンを正確に踏襲していることの裏付けとしても使える。

### B-3. 模擬⑤AM 問12(AIHAとPNHの鑑別)
> 自己免疫性溶血性貧血の所見で**誤っている**のはどれか。
> 1. 球状赤血球の出現　2. 網赤血球数の増加　3. 赤血球膜CD55、CD59の欠損　4. 血清間接ビリルビンの増加　5. 血清ハプトグロビンの低下

正答は選択肢3。CD55・CD59の欠損は発作性夜間ヘモグロビン尿症〈PNH〉の所見であり、自己免疫性溶血性貧血〈AIHA〉の所見ではない。同じ「溶血性貧血」でもAIHAとPNHという異なる疾患機序を混同させないための良問で、発展クエストの題材に向く。

## 参考:「溶血」の別の意味で登場する設問(検査法としての溶血反応/細菌の溶血性状)

骨子案4-Aの対象(検体アーチファクト)とも、カテゴリB(疾患)とも異なる第3・第4の文脈として、「補体による溶血反応」を利用した検査法(CH50など)と、「細菌が産生する溶血毒/血液寒天培地上の溶血性状」に関する設問がある。

**補体による溶血反応(検査原理としての溶血)**
- **模擬②PM 問85**: 補体量と溶血度(%)の関係で正しいのはどれか。5つのグラフ(補体量を横軸、溶血度%を縦軸としたS字曲線・単調増加曲線・単調減少曲線など)から選択する形式。正答はS字状に立ち上がり頭打ちになる曲線(補体価測定〈CH50〉の原理:一定量のヒツジ赤血球に対する補体による溶血反応を利用し、50%溶血を与える補体希釈倍数から補体価を求める)。
- **第57回AM 問81**(第52〜59回追加調査で発見): 誤っている組合せはどれか。1. 溶血反応 --- **Donath-Landsteiner反応**　2. 二重免疫拡散法 --- 抗ENA抗体検査　3. 間接蛍光抗体法 --- 抗核抗体検査　4. ラテックス凝集法 --- アレルゲン特異IgE検査　5. 間接赤血球凝集反応 --- 梅毒トレポネーマ抗体検査。誤っている組合せは選択肢4(ラテックス凝集法はアレルゲン特異IgE検査には用いられない。国家試験の解答は未入手のため推定)であり、選択肢1「溶血反応 --- Donath-Landsteiner反応」自体はむしろ**正しい**組合せとして提示されている。Donath-Landsteiner反応(二相性溶血素であるDonath-Landsteiner抗体を検出する、まさに「溶血反応」そのものを利用した検査)を、検査法の名称と原理の対応表という形で正面から扱った設問で、模擬②PM問85・第64回AM問81(いずれもCH50=補体による溶血反応)と並べると「溶血反応」という検査原理が複数の異なる検査法(補体価測定、Donath-Landsteiner反応)に共通して使われていることを示せる。
- **第64回AM 問81**(第63〜70回追加調査で発見): 試験管内で37℃で行った反応のうち、溶血が観察されるのはどれか。2つ選べ。ヒツジ赤血球+モルモット補体、(ヒツジ赤血球+抗ヒツジ赤血球抗体)+モルモット補体、など5通りの組合せ(一部は56℃30分の非働化処理あり)から選ぶ形式。正答は「ヒツジ赤血球+モルモット補体」および「(ヒツジ赤血球+抗ヒツジ赤血球抗体)+モルモット補体」の2つ。抗体と補体がそろって初めて溶血が起こること、56℃処理で補体が非働化され溶血しなくなることを問う、CH50の原理をより詳しく掘り下げた設問で、模擬②PM問85と組み合わせて使える。

**細菌の溶血毒・血液寒天培地上の溶血性状(細菌学的性状としての溶血)**
- **第63回PM 問72**: 細菌と毒素の組合せで正しいのはどれか。2つ選べ。*Clostridium botulinum*—エンテロトキシン、*Shigella dysenteriae*—耐熱性溶血毒、*Staphylococcus aureus*—皮膚剝脱毒素、*Streptococcus pyogenes*—発赤毒素、*Vibrio parahaemolyticus*—ベロ毒素。正答は*S. aureus*と*S. pyogenes*の組合せ。「耐熱性溶血毒」は本来*V. parahaemolyticus*(腸炎ビブリオ)の毒素であり、「ベロ毒素」は本来腸管出血性大腸菌の毒素であることを利用して、*Shigella*と*Vibrio*の行でわざと取り違えたひっかけになっている。
- **第69回AM 問75**: 細菌と毒素の組合せで誤っているのはどれか。*Clostridium tetani*—神経毒素、Enterohemorrhagic *Escherichia coli*〈EHEC〉—ベロ毒素、*Staphylococcus aureus*—エンテロトキシン、*Streptococcus pyogenes*—毒素性ショック症候群毒素、*Vibrio parahaemolyticus*—**耐熱性溶血毒**。上の第63回PM問72と対照させると、「耐熱性溶血毒=腸炎ビブリオの毒素」という同じ知識が正しい組合せとして問われている回と誤りとして問われている回があり、細菌毒素と「溶血」という語の結び付きを整理する教材として有用。
- **第63回PM 問75**: *Bacillus anthracis*(炭疽菌)で正しいのはどれか。1. 鞭毛を有する。2. 端在性芽胞を有する。3. β-ラクタマーゼを産生する。4. **レシチナーゼテストが陽性である。**5. ヒツジ血液寒天培地でβ溶血を示す。正答4。炭疽菌はヒツジ血液寒天培地では**非溶血性**(選択肢5は誤り)であり、これは同じ*Bacillus*属でβ溶血を示す*B. cereus*などとの重要な鑑別点になっている。
- **第67回PM 問69**: 血液培養陽性ボトルのGram染色標本を提示。35℃・炭酸ガス培養後のヒツジ血液寒天培地上のコロニーは**β溶血**を示し、カタラーゼ試験陰性・PYR試験陽性であった。推定される菌はどれか。正答は*Streptococcus pyogenes*(A群溶血性レンサ球菌)。前述2問とは逆に、血液寒天培地上の溶血性状を**同定の手がかりとして正しく使う**設問で、細菌学実習の教材と直結させやすい。
- **第68回PM 問78**: *Listeria monocytogenes*について誤っているのはどれか。1. Gram陽性短桿菌である。2. CAMPテスト陽性である。3. 馬尿酸塩加水分解試験陽性である。4. エスクリン加水分解試験陽性である。5. **ヒツジ血液寒天培地でα溶血性を示す。**正答5(誤り)。*L. monocytogenes*は実際にはβ溶血性であり、α溶血とする本肢が誤り選択肢。上記の炭疽菌の問題(非溶血性)と合わせ、「溶血の有無・型(α/β/非溶血)」が細菌鑑別の重要な着眼点であることを繰り返し確認できる。

「溶血」という同じ語が、①検体アーチファクト、②疾患(溶血性貧血)、③検査原理(補体による溶血反応)、④細菌学的性状(溶血毒・血液寒天培地の溶血パターン)という4通りの文脈で登場することを示す好例であり、生徒が混同しやすいポイントとして章の導入や用語整理コーナーで触れる価値がある。

## 参考:輸血による溶血反応(輸血副作用としての溶血)

- **第66回PM 問89**: 抗HLA抗体が原因となるのはどれか。2つ選べ。輸血後GVHD、**血小板輸血不応**、遅発性溶血性輸血副作用、**臓器移植後の急性拒絶反応**、輸血関連循環過負荷TACO。正答は血小板輸血不応・急性拒絶反応(「遅発性溶血性輸血副作用」はHLA抗体ではなく赤血球抗原に対する不規則抗体が原因である点に注意)。

### 冒険の書 4-A / 新型クエストへの活用として特に有用な設問(上位7件)

1. **模擬②AM1 問14**「採血を手間どった患者の血液検査で、溶血により高値となるのはどれか」— 臨床場面の描写がそのままクエスト導入文に転用できる。選択肢がNa/Cl/Ca/pH/Hbという「溶血で変化しない項目 vs する項目」の仕分けになっており、暗号解錠型(正しい項目だけを選んで鍵を開ける)にそのまま流用可能。
2. **模擬②AM1 問36 / 第70回PM 問39 / 第58回AM 問30・問37の4点セット**(AST・アンモニアそれぞれについて「溶血で低値」という誤り選択肢と「溶血で上昇する」という正しい選択肢がペアで存在)— 「溶血=対象物質の高値」という基本則を、誤り版・正答版の両方から国家試験の実例で裏付けられる、章の核心教材群。特にAST(模擬②AM1問36 vs 第58回AM問30)は同一項目の表裏がそろった唯一の組。
3. **第63回PM 問13**「血清と比較した血漿検体の特徴で正しいのはどれか」(正答:血漿はLD活性の偽高値が少ない)— 採血管・検体の種類(血清 vs 血漿)そのものが溶血由来の測定誤差を左右するという、骨子案4-Aの論点に最も直接的に対応する国家試験本試験の設問。
4. **第62回PM 問33 / 模擬①PM 問37 のHbA1cペア**(+第65回AM問38, 第66回AM問33, 第67回AM問29で計5回分の類題を確認)— 検体そのものの溶血ではなく患者体内の溶血(溶血性貧血)がHbA1cという間接指標に与える影響を扱っており、A・B両カテゴリの橋渡しとして章の発展部分(なぜ赤血球の寿命が検査値に影響するのか)に使える。国家試験での出題頻度が高く、章の応用パートの主軸にできる。
