# 一次資料調査カタログ:採血管と抗凝固剤(冒険の書 第2章 用)

『冒険の書』第2章「採血管と抗凝固剤」(骨子案 大項目2、中項目A〜E・小項目20個)の元ネタ調査記録。

## 1. 一次資料

### アプリ内既存コンテンツ `content/series/bio-tubes.mjs`(clinical-content-reviewer PASS済み)
2026-08-20にPASS済みの4ユニット(u2〜u5、中項目B/C-a/C-b〜e/D/E相当)の講義・調査カード本文をベースとして再利用した。EDTAの偽低値項目(Ca・Mg・ALP・鉄)・偽高値項目(K)、NaF・ヘパリンの影響、クエン酸の希釈効果とTDM吸着、血清/ヘパリン血漿のK差(血小板由来)、迅速報告の利点、採血量不足・過剰充填の影響は、いずれもこの既存アプリ内容を出発点にしている。

### 当院の実SOP(2026-08-27にユーザーから提供)
- `■検査案内　容器一覧.pdf`(技04-Ⅲ共通040、2025年9月版): 当院で実際に使われている採血管①〜㊵の一覧(容器名称・添加剤・主な検査項目・採血時の注意)。A節「◆当院の例」の一覧表の出典。血清用(シリカ/トロンビン+分離剤)・EDTA-2K(紫蓋・濃紫蓋・桃蓋2種)・EDTA-2K+NaF(灰蓋)・クエン酸ナトリウム(黒蓋・赤沈用3.8%)・ヘパリン(濃緑蓋)・ヘパリンナトリウム(イオン化カルシウム用)・EDTA-2Na(黄緑蓋、アプロチニン入り)・ビタミン用遮光管などを確認。
- `■検査案内.pdf`(技04-Ⅲ共通006)IX.検体採取方法・3.採血による検査データへの影響への留意点: 「採血から遠心分離までの時間は1時間以内。特に血糖値はNaFを加えても阻止剤が働くまでに1時間程度かかり、この間血糖値は1〜5 mg/dL程度減少する」という具体的な数値と、「EDTAを使用すると、時として血小板凝集塊形成や血小板が好中球に吸着され見かけ上血小板が減少する。また血小板凝集塊を白血球としてカウントされるため見かけ上白血球数は増加する」というEDTA依存性偽性血小板減少の記載を確認(C節コラム②の出典)。同文書はQFT専用管の採取順序(灰色→緑色→黄色→紫色)も記載しているが、これはキット内手順でありB節の「複数の検査項目間のキャリーオーバー対策としての順序」とは別物と整理した(B節注意ボックス参照)。
- `■検体受け入れ手順書.pdf`(技04-Ⅲ共通011): 「外部-421028 標準採血法ガイドライン(GP4-A3)」への参照を確認(一般的な採取順序の外部典拠として)。原文自体はローカルに保有していないため、順序の具体的な並びはアプリ既存コンテンツ(bio-tubes.mjs、教科書的に広く教えられている順序として記載)を踏襲した。

### Web検索で補強した事実(ヘパリンLi/Naの使い分け)
骨子案C「ヘパリンリチウム／ナトリウム管」の区別は、既存アプリ内容(ヘパリンとしか区別していない)にはなかったため、Web検索で補強した。生化学検査でヘパリンリチウムが標準的に使われるのは、ヘパリンナトリウムを使うとナトリウムが測定対象のNa値に混入するためであり、逆にリチウム製剤の血中濃度(TDM)を測る場合はヘパリンリチウム管が使えない(Liそのものが偽高値になる)、という相互排他的な関係を確認した。当院の容器一覧でも、ヘパリンナトリウム管はイオン化カルシウム測定・染色体検査など、Na測定を伴わない用途に限定的に使われている実例を確認し、本文コラム①として整理した。

## 3. 既存アプリコンテンツとの関係

本章はアプリ内`bio-tubes`ステージの5ユニット(u1〜u5)が既にカバーしている範囲を土台にしつつ、書籍版としてより体系的に(A〜Eの中項目構成で)再編し、以下を新規に追加した。
- A節: 採血管の種類そのものの分類・仕組みの説明(既存アプリu1は「色が違う管が届いた」という限定的なケースのみで、a〜fの網羅的な説明は無かった)
- ヘパリンリチウム／ナトリウムの区別(既存アプリには無かった)
- 赤沈用クエン酸(3.8%)と凝固検査用クエン酸(3.2%)の違い
- EDTA依存性偽性血小板減少(既存アプリのEDTAの説明はキレート機序のみ)
- 当院の実際の採血管一覧・具体的な数値(NaFの効果発現までの時間、転倒混和回数)
