## 候補1(基礎知識・単一選択)

**Q. 採血に手間どった患者の血液検体で、溶血により高値となるのはどれか。**

1. Na
2. Cl
3. Ca
4. pH
5. ヘモグロビン〈Hb〉

**正答: 5**

**解説**: 赤血球内に含まれる成分そのものであるヘモグロビンは、溶血によって血漿中にそのまま漏出するため上昇する。他の選択肢(電解質・pH)は溶血の影響を強く受けない。「K(カリウム)が選択肢にない」点に注意し、一面的な暗記に頼らないこと。

**出典**: 模擬試験(模擬②AM1問14)を改変

## 候補2(ひっかけ・単一選択)

**Q. AST について正しいのはどれか。**

1. 溶血検体では低値を示す
2. 赤血球にはほとんど含まれない
3. ALTより赤血球内濃度が低い
4. 溶血検体では高値を示す
5. 溶血の影響を受けない

**正答: 4**

**解説**: ASTは赤血球内に血漿の20〜40倍の濃度で存在するため、溶血検体では高値を示す。選択肢1・5は方向を取り違えた誤り。

**出典**: 国家試験(模擬②AM1問36 / 第58回AM問30)を改変

## 候補3(ひっかけ・単一選択)

**Q. 血中アンモニア濃度について正しいのはどれか。**

1. 溶血検体では低値を示す
2. 溶血検体では高値を示す
3. 溶血の影響を受けない
4. 赤血球にはほとんど含まれない
5. 採血後は室温で保存してよい

**正答: 2**

**解説**: アンモニアも赤血球内濃度が血漿より高く、溶血検体では高値を示す(「低値を示す」は誤り選択肢としてよく使われる)。なお、アンモニアは室温放置でも上昇するため、採血後は速やかに冷却・測定する必要がある。

**出典**: 国家試験(第70回PM問39 / 第58回AM問37)を改変

## 候補4(応用・複数選択)

**Q. 溶血性貧血の患者で低値を示すのはどれか(2つ選べ)。**

1. LD
2. 間接ビリルビン
3. ハプトグロビン
4. 網赤血球数
5. HbA1c

**正答: 3・5**

**解説**: 溶血性貧血(体内溶血)では、LD・間接ビリルビン・網赤血球数はいずれも上昇する。ハプトグロビンは遊離ヘモグロビンとの結合により消費され低下し、HbA1cは赤血球寿命の短縮により低値となる。「検体そのものの溶血」と「体内溶血」の違いを理解しているかを試す総合確認問題(本文コラム②・④に対応)。

**出典**: 国家試験(第61回AM問64 / 第62回PM問33等)を改変・合成

## 候補5(応用・単一選択)

**Q. 血清と比較した血漿検体の特徴として正しいのはどれか。**

1. 溶血によるLDの偽高値が生じやすい
2. 溶血によるLDの偽高値が生じにくい
3. 凝固に時間がかかる
4. 総蛋白の測定に用いることができない
5. 遠心操作が不要である

**正答: 2**

**解説**: 血漿検体は血清検体に比べて、溶血によるLDの偽高値が生じにくいことが知られている。採血管・検体の種類の選択自体が、後の測定における溶血の影響にまで関わってくる例。

**出典**: 国家試験(第63回PM問13)を改変

**当院運用メモ**: 当院は血清を使用しているため、この設問は「自施設が採用していない検体種類との比較で注意点を学ぶ」発展的な位置づけとして使うか、逆に「血清を使う当院では、血漿を使う施設よりもLDの偽高値によりいっそう注意が必要」という文脈で出題すると実務に直結する。
