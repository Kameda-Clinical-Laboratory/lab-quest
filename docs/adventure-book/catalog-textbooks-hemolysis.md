### 【雑誌】検査値への影響.pdf(『臨床検査』vol.57 no.11 2013年増刊号、医学書院)
今回の調査の中で**最も的を絞った直接の一次資料**。「溶血の検査影響」という専用記事(出居真由美・三宅一徳、順天堂大学医学部臨床検査医学講座、誌面p.1422–1423)が丸ごと存在する。

- **表1(赤血球・血漿中の濃度比)**: Na(0.1・↓)、K(23倍・↑↑)、Fe(97倍・ほぼ変化なし)、総蛋白(8.5倍・↑)、ビリルビン(赤血球中に存在しない・↓)、ブドウ糖(0.8倍・変化なし)、AST(40倍・↑↑)、ALT(7倍・↑)、LD(160倍・↑↑↑)、酸性ホスファターゼ(67倍・↑↑↑)、アルドラーゼ(150倍・↑↑↑)。〔三宅一徳:採血法.標準臨床検査学 臨床検査総論、医学書院、2013より改変〕
- **図1**: 血清ヘモグロビン濃度(0〜700mg/dL)に対する測定値の変化比のグラフ。LDが最も急峻に上昇(約4.7倍まで)、AST(約2.6倍)、K(約1.3倍)の順で溶血感受性が異なることを可視化。
- 本文の骨子:
  1. 赤血球/血清成分の含有比率の違いによる影響 — 比率が高い項目(LD160倍、AST40倍、K23倍)は軽度の溶血でも偽高値になりやすい。反対に赤血球中濃度が低い項目(Naなど)は偽低値になる。鉄は血清鉄測定法がトランスフェリン結合鉄のみを測るためヘモグロビン鉄を測り込まず、溶血の影響を受けにくい。NSE(神経特異エノラーゼ)も赤血球に含まれ、溶血検体では偽高値となるため採血のやり直しが必要。
  2. ヘモグロビンの色調による測光妨害 — 比色測定項目に直接妨害。自動分析装置では二波長測光や検体ブランク測定(2ポイントエンド法)で最小限に抑制。総蛋白のように光学的妨害を回避してもヘモグロビン自体を蛋白として測り込むため正誤差が残る項目もある。自動分析装置は溶血度(溶血指数)を二波長比色測定と演算により相対値として表示するが、①この溶血度は標準化されていない相対値であり機種・施設間で値が異なる、②溶血の程度と赤血球内成分の増分の関係はおおむね比例するが、LD単独高値のような場合は溶血のみを原因と断定できない例があり悪性腫瘍の見落とし等の危険があるため、溶血度の数値を検査結果の解釈にそのまま利用するのは困難、という限界が明記されている(施設差・報告方針を考える上で重要な記述)。
  3. 溶血で漏出した成分の影響 — インスリン・BNP・ACTHなどペプチドホルモンは、赤血球から漏出したプロテアーゼにより分解され偽低値になる。インスリン測定では、NaFとクエン酸ナトリウムを添加したFC採血管を使うと血液pHが低く保たれ、インスリン分解酵素(IDE)が失活するため溶血の影響を回避できる。
  4. 血清蛋白分画への影響 — ヘモグロビンのバンドがβ分画付近に検出されるため、M蛋白と誤認しないよう注意が必要。

同じ号には隣接記事として「黄疸の検査影響」(誌面p.1418–1419)と「検査値への乳びの影響の調べ方」(誌面p.1420–1421)もあり、干渉三兄弟(溶血=Hemolysis・黄疸=Icterus・乳び=Lipemia、いわゆるHIL)を扱う特集であることがわかる。今回は溶血記事のみ重点的に読み込んだ。

## 2. 溶血によって偽高値になる項目(統合リスト・理由つき)

赤血球/血漿の濃度比が高いほど、少量の溶血でも上昇幅が大きくなる。数値は主に赤本臨床化学(表I-15)と検査値への影響誌(表1)の一致する値。

| 項目 | 赤血球/血漿 濃度比(目安) | 理由・備考 |
|---|---|---|
| LD(LDH) | 約160倍 | 溶血感受性が最も高い代表項目。軽度の溶血でも偽高値。LD1≒LD2>LD3の比率で赤血球に存在 |
| 酸性ホスファターゼ(AcP) | 約67倍 | |
| アルドラーゼ | 約150倍 | |
| AST(GOT) | 約20〜40倍(資料により差) | ALTより溶血感受性が高い |
| K(カリウム) | 約23倍 | 採血手技由来の溶血でも上昇しやすく、パニック値誤報告のリスクが高い |
| 総蛋白(TP) | 約8.5倍 | ヘモグロビン自体を蛋白として測り込むため、光学的妨害を補正しても正誤差が残る |
| ALT(GPT) | 約7倍 | ASTやLDに比べ溶血の影響は小さい(赤本では「溶血の影響はない」と明記) |
| Fe(鉄) | 約97倍(RBC内濃度としては高い) | ただし血清鉄測定法はトランスフェリン結合鉄のみを測定しヘモグロビン鉄を測り込まないため、実際の測定値への影響は小さい(表記上は「変化なし」に近い) |
| NSE(神経特異エノラーゼ) | – | 赤血球にも含まれ溶血検体で偽高値。腫瘍マーカーとして再採血が必要になる代表例 |
| ブドウ糖 | 約0.8倍(赤血球側がやや低い) | 資料によっては「変化なし」扱い |

## 3. 溶血によって偽低値になる項目

| 項目 | 理由 |
|---|---|
| Na(ナトリウム) | 赤血球/血漿比が約0.1と低く、溶血により血漿が希釈されるかたちで見かけ上低下 |
| ビリルビン | 赤血球中にほぼ存在しないため、溶血により相対的に希釈され偽低値になりうる |

## 4. 溶血指数(溶血度)の考え方と許容限界

- 自動分析装置は、検体情報として二波長比色測定を行い、演算によって「溶血度」を相対値として表示する仕組みを持つ(検査値への影響誌より)。
- ただしこの溶血度には明確な限界がある:
  1. **標準化されていない相対値**であり、機種・施設によって値が異なる(施設差が大きい)。
  2. 溶血の程度と赤血球内成分の増分の関係は**おおむね比例**するが、例えばLD単独高値のようなケースでは溶血のみが原因と断定できない場合があり、悪性腫瘍などの見逃しにつながる危険がある。そのため**溶血度の数値そのものを検査結果の解釈に直接利用するのは困難**、というのがこの分野の専門家(出居・三宅、順天堂大学)の結論。
- 干渉チェックの一般的な方法としては、ヘモグロビン純品を用いた干渉チェック用試薬(例:シスメックス社「干渉チェック・Aプラス」、黄疸・乳びの回で同種の方法が紹介されている)で用量反応的に妨害の有無を確認するのが標準的アプローチ。
- 臨床検査総論の実務的な観点では、「溶血を絶対に避けるべき項目」として黄疸指数・血漿ヘモグロビン値・総コレステロール・各種酵素活性・カリウム・マグネシウム・鉄が明示されており、これらの項目については数値基準よりも「溶血を起こさない採血手技」そのものが第一の対策として教えられている。

## 5. 報告時の対応方針(施設差を含む)

検査値への影響誌の記述をもとにした一般的なワークフロー(乳びの回のフローチャートが溶血にもほぼ準用できる形で誌面に整理されている):

1. 血清情報(溶血の有無)と測定結果(異常値・パニック値の有無)を確認する。
2. 溶血(+)の場合は検体を確認、溶血(−)の場合は前回値をチェックする。
3. 異常値(パニック値)項目については、反応過程(タイムコース)の確認・再検を行う。
4. 異常反応が疑われる場合は、①生理食塩水等で希釈した検体の測定、②添加回収試験(既知濃度のプール血清を用いて理論値と実測値を比較)、③測定原理が異なる方法での検査、のいずれかで妨害の有無を精査する。
5. 報告が遅延する場合は状況を担当医に速やかに連絡し、最終結果が出たら担当医に連絡する。
6. LDのように溶血単独では説明できない異常高値の可能性がある項目については、溶血度の数値だけで「溶血のせいだから無視してよい」と判断せず、悪性腫瘍等の見落としリスクを踏まえて慎重に扱う。
7. 溶血度(溶血指数)自体が非標準化の相対値で機種・施設間差があることを、報告・解釈の際の前提として認識しておく必要がある。

## 6. 「4-A 溶血」執筆にあたっての推奨引用元(優先順位)

1. **【雑誌】検査値への影響.pdf「溶血の検査影響」記事(誌面p.1422–1423)** — 表1の赤血球/血漿濃度比、図1の変化比グラフ、溶血指数の限界、ペプチドホルモンの分解機序、蛋白分画への影響まで、この一本で溶血パートの骨格がほぼ組める。
2. **赤本 臨床化学.pdf(PDF p.52 表I-15、PDF p.251–253 LDの項)** — 濃度比表の一次的な出典(Caraway 1962由来)であり、LD160倍・AST40倍という数値の教科書的な裏付けとして使える。ALTは溶血の影響を受けないという対比記述も貴重。
3. **【講義資料】臨床生化学Ⅰ.pdf(seika1、p.3・p.5・p.6)** — AST・LDそれぞれについて図解つきでビジュアル的に説明されており、ゲーム内の「調査ハブ」的なビジュアル素材の参考にもなる。LD160倍・AST40倍という数値は赤本・雑誌記事と完全に一致しており、複数資料でクロスチェック済み。
4. **赤本 臨床検査総論.pdf(PDF p.64、[7]溶血を起こさない注意)** — 採血手技(強い吸引・泡立ち)が溶血の直接原因になることの実務的な説明。「絶対に溶血があってはならない項目」リストは、プレイヤーが採血シーンで注意すべきポイントの脚本化に使いやすい。
5. **【講義資料】臨床化学.pdf(rk、p.8)** — 「採血上の変動要因」として溶血をクレンチング・輸液混入・抗凝固剤混入と並べて整理しており、溶血以外の類似アーチファクトとの対比に使える。

## 7. 調査手法メモ(引き継ぎ用)

- スキャンPDFのテキスト抽出は `pdftotext`/`pypdf`/`pymupdf`のテキスト抽出いずれも文字化けするため使用不可。PyMuPDF (`import pymupdf`) でページをPNGにレンダリングし、Readツールで目視する方法のみが機能した。
- Python実行ファイルは `C:\Users\うめ\AppData\Local\Python\bin\python.exe` を使用(`python3`はWindows Storeスタブで動作しない)。
- 赤本2冊(臨床化学・臨床検査総論)は末尾の索引(和文索引/欧文索引)で「溶血」を検索し、該当ページ番号(印刷ページ)を確認したうえで、印刷ページ番号とPDFページ番号のオフセット(前付けページ数の分だけずれる。書籍中盤で図版挿入により1〜2ページ分ずれが生じることがあるため、索引の値をそのまま鵜呑みにせず前後数ページを実際にレンダリングして確認する必要があった)を逆算してPDFページを特定した。
- レンダリング用スクリプトは `scratchpad/survey-textbooks/render.py`(引数: PDFパス、出力ファイル名prefix、zoom倍率、出力ディレクトリ、カンマ区切りページ番号[1始まり])。
