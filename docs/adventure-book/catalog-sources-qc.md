# 一次資料調査カタログ:精度管理(冒険の書 第8-9章 用)

『冒険の書』第8-9章「精度管理(内部精度管理と外部精度評価)」の元ネタ調査記録。

## 1. 一次資料

### アプリ内既存コンテンツ `content/series/bio-qc.mjs`(clinical-content-reviewer PASS済み)
本章の本文は、既にPASS済みのアプリ内容(u1〜u7、大項目8・9をカバー)の講義本文をほぼそのまま書籍向けの地の文に書き直したものである。個別の事実(Westgardルールの数値、SDI/Z-scoreの目安2/3、トレーサビリティ連鎖、認証標準物質の位置づけなど)はすべてこの既存アプリ内容に基づく。追加調査は行わず、既存の一次資料調査(過去セッションでの`clinical-content-reviewer`による指摘・修正の履歴、`docs/series-roadmap.md`参照)を踏襲した。

### 新規に書き下ろした部分
- 概要節の「正確さ・精密さの的当て図」の説明、8-Aの「シフト」と「トレンド」の違い(シフト=急に一段階ずれてその水準で推移、トレンド=徐々に連続的にずれ続ける)の言葉による説明は、一般的な精度管理の教科書知識として本書側で新たに書き下ろした(アプリの既存レクチャーには「シフト」と「トレンド」の違いそのものの説明は無かった)。
- コラム②(順序を変えた経緯)は、`docs/series-roadmap.md`の2026-08-23の改訂履歴の記述を、学習者向けに要約したもの。

## 2. 図版差し込み枠について

ユーザー指示により、トレンド・シフトの管理図やトレーサビリティ階層図など、実際の図があった方が分かりやすい箇所には`docs/adventure-book/draft/4A-溶血.docx`で確立した図版差し込み枠(点線枠+キャプション)を配置し、実際の画像はユーザー側で挿入する運用とした。今回配置したのは以下4箇所:
- 正確さ・精密さの的当て(ダーツ)図(概要節)
- Levey-Jennings管理図の3パターン(安定・シフト・トレンド)比較図(8-A)
- Westgardマルチルールの判定フローチャート(8-A)
- トレーサビリティ連鎖の階層模式図(9-B)
