# 一次資料調査カタログ:パニック値・緊急異常値の報告(冒険の書 22-A 用)

『冒険の書』第22章「22-A パニック値の設定」の元ネタ調査記録。

**この章は他章(4-A溶血など)と一次資料の性質が異なる**: `docs/materials/`配下の教科書(赤本 臨床化学.pdf・赤本 臨床検査総論.pdf・医学検査概論.pdf 等)の索引を確認したが、いずれも「パニック値」「クリティカルバリュー」の項目立てが無かった(索引に該当エントリなし、目視確認済み)。この分野(検査室の緊急報告体制)は、検査手技や測定原理を扱う一般教科書よりも、学会の運用提言・ガイドラインが一次資料として適切と判断し、`docs/adventure-book/HANDOFF-第4幕リニューアル実装.md`§6の方針(「上記で不足する場合は信頼できるWeb情報で補う」)に従い、日本臨床検査医学会(JSLM)の公式提言書をWeb経由で取得して主たる一次資料とした。

## 1. 一次資料

### 日本臨床検査医学会「臨床検査『パニック値』運用に関する提言書(2024年改定版)」(2024年6月10日)
- 出典URL: https://www.jslm.org/committees/team_med/20240610-1.pdf
- パニック値の定義(Lundberg GD, 1972: "生命が危ぶまれるほど危険な状態にあることを示唆する異常値"で、"直ちに治療を開始すれば救命しうるが、その把握は臨床的な診察だけでは困難で、検査によってのみ可能")を明記。
- 2017年にJSLMチーム医療委員会が実施した全国「パニック値」アンケート調査で、①設定項目・閾値レベルが施設間で不統一、②緊急連絡体制・カルテ記録・臨床的対応の確認方法も施設間で不統一、の2点が明らかになったという経緯を記載(=22-A-c「施設ごとに設定値が異なる理由」の直接の裏付けになる一次資料)。
- 7項目の提言: (1)呼称は対外的には「critical value/クリティカルバリュー」、施設内部では当面「パニック値」も可、(2)項目選定・閾値設定にゴールドスタンダードは無く、添付別表を参考に診療科・医療安全管理部門と協議のうえ施設ごとに個別設定、(3)報告技師への電子カルテアクセス権限付与とパニック値担当技師の任命、(4)原則として初回値(再検査前の値)を報告、再検査せず報告した場合は検体取り違え・患者状態の確認、(5)オーダ医への確実な第一報体制(連絡不能時のエスカレーション)、(6)対応した医師はカルテに時刻・内容・アウトカムまで記録、(7)検体検査に限らず生理機能検査・微生物検査、および院外(在宅医療・衛生検査所・健診施設)にも適用を検討。

### 同「【別表】クリティカルバリュー(通称「パニック値」)の例」(2024年改定版、2021年版から数値変更なしと明記)
- 出典URL: https://www.jslm.org/committees/team_med/20240610-2.pdf
- 血液生化学検査19項目・血液ガス5項目・血液検査6項目・髄液検査2項目、計32行の低値・高値の目安を一覧化した表。うちグルコース・K・Hb・血小板数・PT(INR)の5項目には「緊急報告項目の例(#)」の印が付き、"特に緊急対応(経過観察や処置を含む)を要するため、直ちに担当医への報告が必要となる検査項目の例"と注記。
- 表の脚注に「これら検査項目の選択や基準値の設定は、診療科医師と相談し医療機関ごとに運用されることが望ましい」と明記(=◆施設差の根拠)。
- 参考文献として Lundberg GD 1972(上記) と Harrison's Internal Medicine 第18版 e53(The Clinical Laboratory in Modern Health Care)を明示。
- 表の全数値は下記「2. 統合リスト」に転記した(著作権配慮のため、表の体裁は独自に再構成し、数値・項目名という事実情報のみを引用)。

## 3. 国家試験カタログ(第52〜62回、ローカル保有分をテキスト検索)

`docs/national exam/`配下、テキストレイヤーが生きている回(59・60回)のPDFに対し「パニック」「クリティカル」等のキーワードでテキスト検索を実施(他の回・模擬試験はスキャン画像でテキスト抽出不可、索引の手がかりも無いため今回は対象外)。

### 第59回 午後 問5(`tp130422-05c.pdf`)
> 次の検査結果でパニック値はどれか。
> 1. 血糖 250 mg/dl　2. 血清K 5.0 mmol/l　3. 血清Na 147 mmol/l　4. 血清ALT 200 U/l　5. 動脈血酸素分圧(PaO2) 45 torr

解答: 5(PaO2 45 torr)。上記別表のPaO2低値閾値(40 Torr)に近い高度な低酸素血症であり、他の選択肢(血糖250・K5.0・Na147・ALT200)はいずれも別表の閾値に遠く届かない軽度異常値である。「パニック値=生命の危険に直結する高度な異常」という定義そのものを問う設問として、章末の理解確認に使える良問(ドリル転用候補、下記「4」参照)。

### 第60回 問3(`tp140512-05c.pdf`)
> $\bar{x}$-R管理図法で管理するのはどれか。2つ選べ。
> 1. 標準液の劣化　2. 検体採血過誤　3. 測定値の正確さ　4. パニック値の検出　5. 試薬のロット間差

パニック値の検出は選択肢4として設問中に登場するが正解ではない(正解は精度管理=内部精度管理の話であり、$\bar{x}$-R管理図はランダム誤差・系統誤差の検出に使うもので、パニック値の検出はそれとは別軸の話)。「パニック値の検出」と「精度管理(management図法)」を混同させる出題であり、22-Aと8番(内部精度管理・`bio-qc`)の違いを整理するのに使える。
