# 序 この基準の位置づけと使い方

## 0.1 構成の考え方

日本臨床検査同学院「二級臨床検査士 臨床化学 出題基準」と同じ **大項目 → 中項目 → 小項目** の3階層で記述する。ただし配列の軸を、学問体系（糖質・蛋白質・脂質…）ではなく **検査プロセス（検査前 → 検査 → 検査後）** に置き換えた。理由は以下のとおり。

- 臨地実習で学生が実際に立つ場所は「検体の流れ」の上であり、学問体系の順には並んでいない
- 「臨地実習指針2026」Ⅰ-1-2）目標③が「提供する臨床検査情報の意義、精度管理の必要性」を挙げており、検査前後を含む一連の品質保証の理解を求めている
- 溶血・採血管・SOPといった主題は、学問体系上は分散するが、検査前プロセスとしては一つの塊になる

学問体系側（国試出題基準Ⅳ章・Ⅷ章／二級出題基準）との対応は **付録D** の対応表で担保する。

## 0.2 記号の凡例

「臨地実習指針2026」Ⅱ 実習項目の区分に対応。大項目・中項目の行末に付す。

- **〔見◎〕** 指針の「必ず見学させる行為」に該当、または直結する項目（精度管理〈生化学・免疫〉、メンテナンス作業、チーム医療〈NST・ICT・糖尿病療養指導〉など）
- **〔実○〕** 指針の「実施させることが望ましい行為」に該当する項目（血液ガス分析検査など）
- **〔見〕** 上記以外で観察により学ぶ項目
- **〔調〕** 調査・自習（アプリ内学習で完結しうる）
- **★** 症例が作りやすく学習密度が高い、優先着手候補
- **◆** 施設差が大きく「自施設手順優先」と明記すべき小項目

> 採血行為そのものは法令上の医行為であり、学生の対人採血練習は指針上「望ましい行為」に含まれない。採血管を扱う大項目2 は、手技の観察と原理の理解に限る。

# Ⅰ 検査前プロセス（Pre-analytical Process）

検査値の変動要因のうち最も大きな割合を占め、かつ実習生が最も多く立ち会う工程。主題は「良い検体とは何か」「悪い検体をどう見抜き、どう扱うか」に集約される。

## 1 検査の依頼と受付

### A 患者確認と検体識別 〔見◎〕

- a 患者誤認防止（フルネーム・生年月日・ID による照合）
- b 検体ラベルとバーコードの運用
- c 検体と依頼の突合（3点照合）
- d 検体識別エラーが検査値に与える影響

## 2 採血管と抗凝固剤 ★

### A 採血管の種類 〔見◎〕

- a プレイン管、血清分離剤入り管
- b EDTA-2K／2Na 管
- c ヘパリンリチウム／ナトリウム管
- d クエン酸ナトリウム管（3.2%、1:9）
- e フッ化ナトリウム（NaF）＋解糖阻止剤管
- f 微量元素用・特殊採血管

### B 採血管の採取順序 〔調〕

- a 推奨される採取順序とその根拠
- b 添加物の持ち込み（キャリーオーバー）による誤差
- c 順序違反が生じたときの影響項目の推定

### C 抗凝固剤・添加物の影響 〔調〕

- a EDTA → Ca・Mg・ALP・鉄 の偽低値、K の偽高値
- b ヘパリン → 蛋白分画のβ-γブリッジ様所見、一部免疫測定の干渉
- c NaF → 解糖阻止の機序と限界（初期数時間は完全でない）
- d クエン酸 → 希釈効果（ヘマトクリット高値時の補正）
- e 血清分離剤への薬物の吸着（TDM）

### D 血清と血漿の使い分け 〔調〕

- a フィブリノゲンの有無による測定値差
- b K 値が血清＞血漿となる理由（血小板由来）
- c 迅速報告における血漿検体の利点
- d 施設で採用している検体種の確認 ◆

### E 採血量と充填 〔見〕

- a 規定量未満（採血不足）の影響
- b 抗凝固剤と血液の比率
- c 過剰充填・凝固不十分による凝固検体

## 3 検体の搬送・受付・前処理

### A 搬送 〔見〕

- a 気送管（エアシューター）による溶血・血小板活性化
- b 外来・病棟・外部委託の搬送経路の違い ◆
- c 血液ガス検体の搬送（気泡除去、時間）

### B 受付と分注 〔見◎〕

- a 検体到着時の外観チェックポイント
- b 分注時のコンタミネーション防止
- c 検体不足・不適検体の判定と連絡 ◆

### C 遠心分離 〔見◎〕

- a 遠心の原理（相対遠心力 RCF と回転数の換算）
- b 項目別の遠心条件（回転数・時間・温度）
- c 遠心前の完全凝固待ち時間
- d 血清分離剤の働きと分離不良
- e 再遠心が許されない場面

### D 検査室内の検体の流れ 〔見〕

- a 受付 → 遠心 → 分注 → 分析 → 保管 の動線
- b 検体搬送システム（ラボオートメーション）

## 4 検体の性状と測定妨害 ★

### A 溶血 〔見◎〕

- a 溶血の成因（採血手技・搬送・遠心・病態、体外溶血と体内溶血の区別）
- b 溶血指数（H）の測定原理と表示
- c 偽高値となる項目：K、LD、AST、鉄、ALT、Mg、リン、NSE
- d 偽低値となる項目：インスリン、ハプトグロビン、ビリルビン（一部法）
- e 溶血の程度と許容限界の考え方
- f 溶血検体の報告方針（再採血・コメント付与・報告見合わせ） ◆

### B 乳び（脂肪血） 〔見〕

- a 成因（食後、TG高値、脂肪乳剤輸液）
- b 乳び指数（L）と光散乱による測定妨害
- c 対処（超遠心、乳び除去試薬、希釈、測定法の変更）
- d 影響を受けやすい項目

## 5 検体の保存と安定性

### A 保存条件 〔調〕

- a 室温・冷蔵（4℃）・冷凍（-20℃／-80℃）の使い分け
- b 凍結融解の繰り返しによる変性
- c 全血のまま放置した場合の変化（K上昇、Glu低下）
- d 保存容器・蒸発による濃縮

## 6 標準作業書（SOP）と精度確保の枠組み ★

### A 法的枠組み 〔調〕

- a 医療法改正（2018年施行）による検体検査の精度確保
- b 標準作業書、作業日誌、台帳の3点セット
- c ISO 15189 と日臨技品質保証施設認証

### B 標準作業書の実際 〔見◎〕

- a 検査機器保守管理標準作業書
- b 測定標準作業書（項目ごとの記載事項）
- c 手順書の階層（方針 → 手順 → 記録様式）
- d 実習先の SOP を実際に読む（構成と記載粒度の確認） ◆

# Ⅱ 検査プロセス（Analytical Process）

「なぜその値が出たのか」を測定原理まで遡って説明できることが到達点。二級臨床検査士出題基準Ⅲ「臨床化学」の大項目1〜15、および国試出題基準Ⅳ章・Ⅷ章の中核がここに入る。

## 7 分析の基礎原理

### A 吸光光度法・比色系 ★ 〔見◎〕

- a Lambert-Beer の法則
- b モル吸光係数と濃度計算
- c 吸収光と補色、測定波長の選択
- d 主波長・副波長（二波長測定）による濁り補正

### B 代表的な発色系・反応系 〔調〕

- a NAD(P)H の 340 nm 吸光度変化（酸化還元系）
- b 酵素電極法・イオン選択電極法（希釈法と非希釈法、偽性低Na血症）

### C 自動分析装置 ★ 〔見◎〕

- a ディスクリート方式の動作（サンプリング → 試薬添加 → 測光）
- b 反応タイムコースの読み方（レートアッセイ／エンドポイント）
- c プロゾーン（地帯現象）・フック効果の検知

## 8 内部精度管理 ★

### A 管理図法 〔見◎〕

- a Levey-Jennings 管理図の見方
- b X-R(s) 管理図法
- c Westgard マルチルール（1-2s、1-3s、2-2s、R-4s、4-1s、10x）
- d 系統誤差（シフト・トレンド）と偶然誤差の判別

### B 患者データを用いる方法 〔調〕

- a デルタチェック法
- b 累積和法（CUSUM）
- c 正常値平均法（患者データ平均法）
- d 項目間チェック法
- e 機器管理法と患者データ法の使い分け（国試頻出の区別）

### C 誤差論 〔調〕

- a 誤差の分類（系統誤差・偶然誤差・過失誤差）
- b 正確さ（trueness）と精密さ（precision）の区別
- c 併行精度と室内再現精度
- d 不確かさの考え方

## 9 外部精度評価と標準化 ★

### A 外部精度評価 〔見◎〕

- a 日臨技臨床検査精度管理調査、日本医師会精度管理調査、都道府県調査
- b サーベイの流れ（試料配布 → 測定 → 提出 → 評価報告）
- c 評価指標の読み方（SDI、Z-score、評価点）
- d 不良評価時の原因追及と是正

### B 標準化とトレーサビリティ 〔調〕

- a トレーサビリティ連鎖
- b 一次標準物質・二次標準物質・認証標準物質・常用標準物質
- c JSCC 勧告法、IFCC 準拠法
- d ALP の IFCC 法移行など、測定法変更に伴う基準範囲の変化
- e 共用基準範囲

### C 施設間差と方法間差 〔調〕

- a 同一項目でも施設で値が異なる理由
- b 試薬・機器更新時の相関試験と成績の継承
- c 前値との連続性を臨床にどう説明するか
- d 検査値の標準化が診療にもたらす意味

## 10 装置・試薬の日常管理

### A 保守点検 〔見◎〕

- a 始業点検・終業点検の項目
- b 日常・週次・月次メンテナンス
- c 光源・分注プローブ・反応セルの管理
- d 純水装置と水質

### B 校正（キャリブレーション） 〔見◎〕

- a 校正のタイミング（ロット変更、部品交換、管理逸脱時）
- b 校正曲線の妥当性確認

### C 試薬管理 〔見〕

- a ロット管理・有効期限・開封後安定性
- b ロット間差の確認手順
- c 保管条件と在庫管理
- d 試薬調製と記録

## 11 糖代謝関連検査 ★

### A 血糖 〔見◎〕

- a ヘキソキナーゼ-G6PDH 法の反応系
- b グルコースオキシダーゼ（GOD）法、グルコースデヒドロゲナーゼ法
- c 解糖による低下と NaF 採血管
- d 全血・血漿・血清での値の差
- e 低血糖・著明高血糖のパニック値対応 ◆

### B HbA1c 〔見◎〕

- a 糖化ヘモグロビンの生成機序と反映期間（約1〜2か月）
- b HPLC（イオン交換）法のクロマトグラム
- c 免疫法・酵素法の原理
- d 異常ヘモグロビン・貧血・腎不全による偽値

### C その他の血糖コントロール指標 〔調〕

- a グリコアルブミン（反映期間約2週間）
- b 1,5-アンヒドログルシトール
- c 各指標の使い分け（透析、妊娠、急激な変動時）

### D 糖尿病の診断と療養 〔調〕

- a 糖尿病型の判定基準（空腹時、随時、75gOGTT、HbA1c）
- b 75gOGTT の実施手順と採血タイミング
- c インスリン・Cペプチド・抗GAD抗体

## 12 蛋白質・窒素代謝と腎機能 ★

### A 蛋白質 〔見◎〕

- a 総蛋白（ビウレット法）
- b アルブミン（BCG法とBCP改良法の差、値の乖離）
- c 蛋白分画（セ・ア膜電気泳動）とデンシトグラム
- d 異常パターンの読影：M蛋白、ネフローゼ型、肝硬変型（β-γブリッジ）、炎症型、無γグロブリン
- e 栄養アセスメント蛋白（RTP：プレアルブミン、トランスフェリン、RBP）
- f 急性相反応蛋白（CRP、ハプトグロビン、α1-AG）

### B 非蛋白性窒素 〔見〕

- a アンモニア（採血後の急速処理、偽高値の要因）
- b BUN/Cr 比の意味（腎前性・腎性の鑑別）

### C 腎機能評価 〔調〕

- a クレアチニンクリアランスと蓄尿
- b eGFR（血清Cr・年齢・性別からの推算）とその限界
- c シスタチンC と eGFRcys
- d CKD 重症度分類（GFR区分 × 蛋白尿区分）
- e 尿蛋白定量・尿アルブミン

## 13 肝・胆道系検査 ★

### A 逸脱酵素 〔見〕

- a AST／ALT（JSCC勧告法、ピリドキサール-5-リン酸添加の有無）
- b LD とアイソザイム（LD1〜5 と臓器の対応）
- c AST/ALT 比、LD/AST 比の使い方

### B 胆道系酵素 〔見〕

- a ALP（IFCC 法への変更、アイソザイムと骨・肝・胎盤・小腸）
- b γ-GT（飲酒・薬剤による誘導）

### C 合成能・解毒能 〔調〕

- a コリンエステラーゼ
- b アルブミン、コリンエステラーゼ、PT による合成能評価

### D 生体色素 〔調〕

- a ビリルビン代謝経路（間接 → 抱合 → 直接）
- b 黄疸の鑑別（溶血性、肝細胞性、閉塞性、Gilbert症候群、Dubin-Johnson症候群）
- c 肝障害パターンの読み分け（肝細胞障害型／胆汁うっ滞型）

## 14 酵素検査と反応原理 ★

### A 酵素反応速度論 〔調〕

- a 酵素と基質、酵素の分類
- b Michaelis-Menten の式、Km と Vmax
- c Lineweaver-Burk プロット
- d 零次反応と一次反応、初速度分析と終点分析
- e 「最大反応速度の◯% を得る基質濃度」型の計算（国試定番）

### B 酵素活性の測定 〔見◎〕

- a 酵素活性単位の定義（1分間に1μmol の基質を変化させる酵素量）
- b 活性値の計算（吸光度変化率・モル吸光係数・液量比・光路長）
- c 至適条件（温度37℃、pH、基質濃度、補酵素）
- d 共役酵素系（指示酵素）の考え方
- e 試薬盲検・検体盲検

### C アイソザイムと異常 〔見〕

- a LD、ALP、CK、AMY（P型／S型）のアイソザイム分画
- b CK-MB、CK-BB とマクロCK
- c マクロアミラーゼ、マクロALP

### D その他の酵素 〔調〕

- a リパーゼ、ACP、ACE、ADA、NAG、アルドラーゼ
- b 酵素蛋白量の測定（活性値との乖離）

## 15 脂質・電解質・その他生化学

### A 脂質 〔見〕

- a 総コレステロール、HDL-C、LDL-C（直接法と Friedewald 式の適用限界）
- b トリグリセライド（遊離グリセロール消去の有無）
- c 空腹時採血の必要性と non-HDL-C
- d リポ蛋白の分類（CM、VLDL、IDL、LDL、HDL）と比重・粒子径
- e アポ蛋白、Lp(a)、LCAT、遊離脂肪酸、ケトン体
- f 脂質異常症の診断基準

### B 電解質・無機物質 〔見〕

- a Na、K、Cl（イオン選択電極法）

### C 血液ガス 〔実○〕

- a 検体採取（動脈血、ヘパリン、気泡除去、冷却）

## 16 疾患マーカーとPOCT ★

- b イムノクロマトグラフィの原理と判定

# Ⅲ 検査後プロセス（Post-analytical Process）

装置が数値を吐き出してから、その情報が患者の診療判断に使われるまでの工程。実習生にとって最も見えにくく、しかし「臨床検査技師にしかできない仕事」が最も濃い区間。本版では **①結果の妥当性を確認する（20・21）→ ②緊急時に伝える（22）→ ③臨床と協働する（23）** の3段構えで整理した。

## 20 測定結果の技術的妥当性確認 ★

### A 再検・希釈の判断 〔見◎〕

- a 再検基準（施設で定めた再検ルール）の確認 ◆
- b 測定上限超過時の希釈再検と希釈直線性

### B 再採血の判断 〔見〕

- a 再検で解決しない場合の再採血依頼 ◆
- b 患者負担・時間的損失とのバランス
- c 依頼元への伝え方（理由と必要な条件を具体的に）
- d 記録の残し方

## 21 患者データによる結果照合 ★

### A 基準値の3概念 〔調〕

- a 基準範囲（健常者の分布、95% 区間）
- b 臨床判断値（予防医学的閾値・治療閾値・病態識別値）
- c パニック値（極異常値、生命に直結する値）
- d 3者を混同しないことの臨床的意味
- e 共用基準範囲と施設独自の基準範囲 ◆

### B 前回値との比較 〔見◎〕

- a デルタチェックの原理（変化量・変化率・時間）
- b 患者取り違え・検体取り違えの検知
- c 治療介入（輸血、透析、輸液、手術）による正当な変動
- d デルタチェック警告が出たときの確認手順 ◆

### C 項目間の整合性 〔見◎〕

- a Na と Cl の乖離（アニオンギャップ異常）
- b TP と Alb、A/G 比
- c AST・ALT・LD の相互関係、逸脱酵素の組合せ
- d Ca とアルブミン補正（Payne の式）
- e 総ビリルビンと直接ビリルビンの逆転
- f 生化学と血算・凝固・尿検査との整合（例：Hb低値と溶血所見、腎機能と尿所見）

### D 生理的・薬剤性要因の除外 〔調〕

- a 薬剤による検査値変動（ステロイド、利尿薬、スタチン、抗菌薬）
- b 検査値に影響する処置（輸液、輸血、造影剤、透析）
- c 妊娠・加齢・体位による変動
- d 「異常値だが病的でない」パターンの見分け

### E 分析的異常か病態かの切り分け 〔見〕

- a 切り分けの思考手順（装置 → 試薬 → 検体 → 患者）
- b 切り分けの結論をどこまで報告書に書くか ◆

## 22 パニック値・緊急異常値の報告 ★

### A パニック値の設定 〔調〕

- a パニック値／クリティカルバリューの定義
- b 代表的な項目と値 ◆
- c 施設ごとに設定値が異なる理由

## 23 チーム医療への参加 ★

### A 感染制御（ICT／AST） 〔見◎〕

- a ラウンドへの同行と検査室の役割
- b 検査データの活用（培養・薬剤感受性、PCT、プレセプシン、β-D-グルカン）
- c アンチバイオグラムの作成と抗菌薬適正使用

- a NST における検査値の役割
- b 栄養アセスメント蛋白（Alb、プレアルブミン、トランスフェリン、RBP）と半減期の違い

- d 合併症の検査（尿アルブミン、eGFR、脂質）

# 付録A 検査後プロセスの設計意図

検査後プロセスは、しばしば「報告するだけ」と誤解される。実際には、**装置が出した数値は"データ"であって、まだ"検査情報"ではない**。数値を検査情報に変える作業が検査後プロセスであり、次の3つの問いに答える作業に分解できる。

1. **この値は信じてよいか**（大項目20・21）
   分析的な妥当性と、患者文脈での妥当性の二重チェック。前者は装置・試薬・検体を見る目、後者は前回値・他項目・病態を見る目。この二つを両方持っているのが臨床検査技師であり、教育上ここが最大の山場になる。

2. **誰に、いつ、どう伝えるか**（大項目22）
   同じ値でも、伝え方と速さで臨床的価値が変わる。特にパニック値は、正しく測っても伝わらなければゼロになる。「臨地実習指針2026」Ⅲ 事故防止対策でも、パニック値発生時の報告・連絡手順（責任者への報告、連絡経路、記録の残し方）の理解が明記されている。

3. **臨床の問いにどう応えるか**（大項目23）
   チーム医療への参加。指針では「チーム医療（NST、ICT、糖尿病療養指導）」が必ず見学させる行為に指定されており、カリキュラム上も必修扱いにする必要がある。

なお本版では、結果の承認・報告書作成・訂正報告、および検体保管・記録・是正処置を範囲外とした。これらを戻す場合はⅢの末尾に置き、検査前プロセスの SOP（大項目6）へ環が閉じる構成にすると、「品質のループ」が学習者に見える形になる（付録Dの申し送り参照）。

# 付録B ラボクエストへの実装優先度（案）

★印の項目から、症例の作りやすさと国試頻度で優先順位を付けた。

1. **溶血**（4-A、20-A）— 「溶血疑いのK高値を、報告前にどう扱うか決める」
2. **パニック値**（22、21-B）— 「深夜の血糖 22 mg/dL を、誰に、何分以内に、何と伝えるか決める」
3. **採血管**（2-A、2-C）— 「病棟から届いた"Ca が異様に低い"検体の原因を突き止める」
4. **内部精度管理**（8-A、20-A）— 「朝の管理試料が 2-2s に触れた。患者結果を出してよいか決める」
5. **前回値との乖離**（21-B、21-C）— 「前回値と桁が違うクレアチニン。取り違えか、病態か」
6. **心不全マーカー**（16-A）— 「BNP と NT-proBNP、どちらを追えばよいか Dr. に聞かれた」
7. **HbA1c の乖離**（11-B、20-A）— 「血糖は高いのに HbA1c が低い。この患者に何が起きているか」
8. **免疫測定の干渉**（17-C、20-A）— 「腫瘍マーカーだけが極端に高い。フック効果を疑えるか」
9. **SOP**（6-B）— 「手順書と実際の運用が違う。どちらに合わせるべきか」
10. **チーム医療（NST）**（23-B）— 「Alb は低いままだが栄養は改善している。何を見ればよいか」

各シリーズは「シリーズ作成マニュアル」§3 の固定フロー（会話 → 講義 → 調査 → 症例解決 → 発展問題）に従って展開する。

# 付録C 到達目標（プロセス別）

「臨地実習指針2026」Ⅰ-1-2）の4目標を、本カリキュラムの粒度に落とした。

- **検査前**：検体の性状・採取条件が検査値に与える影響を説明でき、不適検体を判断してその理由を依頼元に伝えられる
- **検査**：主要項目の測定原理を説明でき、内部精度管理の逸脱を判定して患者結果を出してよいかの判断過程を述べられる
- **検査後**：得られた値の妥当性を分析的・臨床的の両面から確認し、報告の要否・緊急度・伝え方を判断でき、臨床からの問い合わせに根拠をもって応対できる
- **全体**：一連の工程が精度保証の環として繋がっていることを説明でき、チーム医療における臨床検査技師の役割と責任を自分の言葉で述べられる

## D.4 補強が必要な箇所（次版への申し送り）

第3案で **蛋白質（12-A）** と **酵素活性の測定（14-B）** を復活させた。残る国試カバレッジ上の穴は以下のとおり。優先度の高い順に並べる。

1. **抗核抗体**（国試 ほぼ毎年、別冊写真問題）— 間接蛍光抗体法（HEp-2細胞）の染色パターンと疾患の対応。大項目19 に中項目として戻すか、自己抗体全般で独立させる。
2. **ホルモン**（国試 毎回3〜4問）— 甲状腺（TSH、FT3、FT4）、副腎（コルチゾール、ACTH：検体の急速処理が必要）が実務との接点。17-C の応用として置くのが実習向き。
3. **ビタミン**（国試 毎回3問前後）— 日常検査で測る施設は限られるため、座学寄りにするか 23-B（NST）に絡めて症例化するかの判断が要る。
4. **感染・炎症マーカー**（プロカルシトニン、プレセプシン、β-D-グルカン）— CRP は 12-A-f で拾えるようになったが、敗血症マーカーは 23-A（ICT）で使うのに前提知識がない。16 に中項目として戻すか、23-A の小項目を厚くする。
5. **報告と承認、記録・是正処置** — Ⅲ から外れたため、検査後プロセスが「確認して終わり」になっている。付録A の環を閉じるには、報告書作成・コメント付与・訂正報告を1大項目として戻すのが望ましい。
6. **安全管理**（標準予防策、針刺し対応、感染性廃棄物）— 全削除。指針Ⅲ 事故防止対策との対応上、Ⅰに戻すか、実習オリエンテーション側で担保する旨を明記する。
